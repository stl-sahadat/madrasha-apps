## ✨ মূল বৈশিষ্ট্যসমূহ (Core Features)

### ১. 🎓 শিক্ষার্থী ও ভর্তি ব্যবস্থাপনা (Student & Admissions)
- **স্মার্ট ভর্তি ফরম:** ছবি আপলোড, অটো-জেনারেটেড রোল ও আইডি, অভিভাবকের বিবরণ এবং রক্তের গ্রুপ সমন্বিত ডিজিটাল রেজিস্ট্রেশন।
- **জামাতভিত্তিক শ্রেণি বিভাজন:** নূরানী, নাজেরা, হিফজুল কুরআন থেকে শুরু করে দাওরায়ে হাদিস পর্যন্ত স্বয়ংক্রিয় গ্রেডিং ও শ্রেণি ব্যবস্থাপনা।
- **ডিজিটাল আইডি কার্ড ও প্রশংসাপত্র:** কিউআর কোড (QR Code) যুক্ত স্মার্ট স্টুডেন্ট আইডি কার্ড এবং এক ক্লিকে প্রত্যয়ন পত্র জেনারেশন।

### ২. 🍲 বোর্ডিং, খোরাকী ও খানা হিসাব (Boarding & Khana System)
- **দৈনিক খোরাকী রেজিস্টার:** আবাসিক ছাত্রদের সকাল, দুপুর ও রাতের খাবার ট্র্যাকিং।
- **খোরাকী আদায় ও বিলিং:** মিল চার্ট, দৈনিক ডায়েট ম্যানেজমেন্ট ও বকেয়া হিসাব।
- **বোর্ডিং বাজার তালিকা:** বাবুর্চির দৈনিক বাজার খরচ, পণ্যের তালিকা ও তাৎক্ষণিক ভাউচার প্রস্তুতকরণ।

### ৩. 💰 পূর্ণাঙ্গ হিসাব ও ক্যাশ বুক (Finance & Accounts ERP)
- **দ্বৈত এন্ট্রি ভাউচার সিস্টেম:** আয় ও ব্যয়ের হিসাব, খাতভিত্তিক ক্যাশ ইনফ্লো ও আউটফ্লো।
- **বেতন ও ফি সংগ্রহ:** মাসিক টিউশন ফি, ভর্তি ফি, পরীক্ষা ফি আদায় ও প্রিন্টযোগ্য মানি রসিদ (Money Receipt)।
- **অনুদান ও কালেকশন রেজিস্টার:** সাধারণ দান, আজীবন সদস্য চাঁদা, লিল্লাহ ফান্ড ও যাকাত তহবিলের পুঙ্খানুপুঙ্খ হিসাব।

### ৪. 📝 পরীক্ষা, মেধা তালিকা ও মার্কশিট (Exams & Results)
- **পরীক্ষা সূচি ও অ্যাডমিট কার্ড:** ত্রৈমাসিক, ষাণ্মাসিক ও বার্ষিক পরীক্ষার সিট প্ল্যান ও প্রবেশপত্র।
- **স্বয়ংক্রিয় গ্রেডিং ও মেধা তালিকা:** বিষয়ভিত্তিক নম্বর এন্ট্রি, মারহালাভিত্তিক গ্রেডিং (মুমতাজ, জাইয়্যিদ জিদ্দান, ইত্যাদি) এবং ডিজিটাল মার্কশিট।

### ৫. 📲 হাজিরা, এসএমএস ও অভিভাবক পোর্টাল (Attendance & SMS)
- **দৈনিক হাজিরা:** ছাত্র এবং শিক্ষক/স্টাফদের উপস্থিতি, অনুপস্থিতি ও ছুটির রিপোর্ট।
- **বাংলা ডায়নামিক এসএমএস:** অনুপস্থিতি নোটিফিকেশন, বকেয়া ফি নোটিশ ও জরুরি সাধারণ বার্তা প্রেরণ।
- **অভিভাবক পোর্টাল:** নিজস্ব রোল ও সিকিউর পিন কোড দিয়ে অভিভাবক কর্তৃক শিক্ষার্থীর সার্বিক রিপোর্ট পর্যবেক্ষণ।

## 🚀 ইনস্টলেশন ও লোকাল সেটআপ (Setup & Running)

যেকোনো ডেভেলপার খুব সহজেই তার লোকাল মেশিনে প্রজেক্টটি রান করতে পারেন:

### প্রাক-প্রয়োজনীয়তা (Prerequisites):
- **Node.js:** `v18.17.0` বা এর পরবর্তী সংস্করণ
- **প্যাকেজ ম্যানেজার:** `npm`, `yarn` অথবা `pnpm`

### ধাপ ১: রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/stl-sahadat/madrasha-apps.git
cd madrasha-apps
```

### ধাপ ২: ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ধাপ ৩: ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে **`http://localhost:3000`** এ প্রবেশ করলে সম্পূর্ণ মাদ্রাসা ম্যানেজমেন্ট সিস্টেমটি সরাসরি চালু হবে।

### ধাপ ৪: টাইপস্ক্রিপ্ট ভ্যালিডেশন ও প্রোডাকশন বিল্ড
```bash
# টাইপস্ক্রিপ্ট এরর চেকিং
npx tsc --noEmit

# প্রোডাকশন রেডি বিল্ড
npm run build

# প্রোডাকশন সার্ভার স্টার্ট
npm run start
```

## 📖 মডিউল ও ডেটা ফ্লো গাইড (Module Overview)

1. **সেন্ট্রাল স্টোর ইঞ্জিন (`src/lib/store.ts`):**  
   অ্যাপ্লিকেশনটি সম্পূর্ণ রিয়্যাক্টিভ কাস্টম স্টোর আর্কিটেকচারে তৈরি। যেকোনো এন্ট্রি (নতুন ছাত্র ভর্তি, ভাউচার তৈরি বা ফি আদায়) মুহূর্তের মধ্যে স্টোর আপডেট করে এবং একই সাথে ব্রাউজারের লোকাল স্টোরেজে নিরাপদে ক্যাশ করে রাখে।

2. **প্রিন্ট ও ভাউচার ফরম্যাটিং:**  
   প্রত্যেকটি রসিদ, আইডি কার্ড, প্রশংসাপত্র এবং পরীক্ষার মার্কশিট প্রিন্ট-বান্ধব (`@media print`) ফরম্যাটে ডিজাইন করা হয়েছে। কোনো প্রকার জটিল কনফিগারেশন ছাড়াই সরাসরি A4 সাইজে ঝকঝকে প্রিন্ট আউট নেওয়া সম্ভব।

3. **বহুভাষিক ফন্ট সাপোর্ট:**  
   - সাধারণ বাংলা কনটেন্টের জন্য **`Tiro Bangla`**
   - আধুনিক শিরোনাম ও ড্যাশবোর্ডের জন্য **`Hind Siliguri`**
   - কুরআন ও আরবি কিতাবাতের জন্য **`Amiri`** ফন্ট সংযুক্ত রয়েছে।
