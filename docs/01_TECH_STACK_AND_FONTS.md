## ২. ফন্ট ও টাইপোগ্রাফি আর্কিটেকচার (Bengali Typography)

ইউজার **সাহাদাত ভাই** এর কঠোর নির্দেশনা অনুসারে অ্যাপ্লিকেশনে ফন্ট ব্যবহারের সুস্পষ্ট নিয়ম প্রতিষ্ঠিত রয়েছে:

### ক. সাধারণ টেক্সট ও বডি (Body Font):
- **ফন্ট নাম:** `Tiro Bangla` (তিরো বাংলা)
- **ব্যবহারের স্থান:** সাইটের সকল সাধারণ প্যারাগ্রাফ, টেবিল ডেটা, ইনপুট বক্স, সিলেক্ট ড্রপডাউন, বাটন ও টেক্সট এরিয়া।
- **সিএসএস কনফিগারেশন (`src/app/globals.css`):**
  ```css
  body {
    font-family: 'Tiro Bangla', 'SolaimanLipi', serif;
    background-color: #f8fafc;
    color: #0f172a;
  }
  button, input, select, textarea, table {
    font-family: inherit;
  }
  ```

### খ. হেডলাইন ও টাইটেল (Heading Font):
- **ফন্ট নাম:** `Hind Siliguri` (হিমসাগর / হিমশো)
- **ব্যবহারের স্থান:** সকল সেকশন টাইটেল, কার্ড হেডার, মডাল টাইটেল, পরিসংখ্যান সংখ্যা ও `h1` থেকে `h6` হেডিং ট্যাগ।
- **সিএসএস কনফিগারেশন (`src/app/globals.css`):**
  ```css
  h1, h2, h3, h4, h5, h6, 
  .font-headline, 
  .font-heading,
  .font-title {
    font-family: 'Hind Siliguri', 'SolaimanLipi', sans-serif !important;
  }
  ```

### গ. আরবি ফন্ট (Arabic Font):
- **ফন্ট নাম:** `Amiri`
- **ব্যবহারের স্থান:** ইসলামিক দোয়া, আরবি কিতাবের নাম ও কুরআনের উদ্ধৃতি।

## ৩. গ্লোবাল কালার প্যালেট ও সাইডবার থিম

- **মূল ড্যাশবোর্ড ব্যাকগ্রাউন্ড:** `#f8fafc` (স্লেট ৫০)
- **সাইডবার (Sidebar):** ডার্ক স্লেট (`#0f172a` / `#1e293b`), সক্রিয় মেনু আইটেমের জন্য আধুনিক ইন্ডিগো ও এমারেল্ড হাইলাইট।
- **অ্যাকশন বাটন:**
  - প্রিন্ট বাটন: টিল/সি গ্রিন `#1b686e`
  - পজিটিভ/সেভ বাটন: এমারেল্ড `#059669` / ইন্ডিগো `#4f46e5`
  - ডিলিট/বাতিল: রোজ `#e11d48`
- **গুরুত্বপূর্ণ সতর্কতা:** কোনো নতুন ফিচার যোগ করার সময় বিদ্যমান সাইডবার ব্যাকগ্রাউন্ড বা গ্লোবাল বাটনে এমন সিএসএস যুক্ত করা যাবে না যা সাইডবারের ডার্ক থিম নষ্ট করে দেয়।

## ৪. প্রিন্ট স্টাইল (Print Styles for A4 & POS Slip)

প্রজেক্টে ছাত্রদের প্রত্যয়ন পত্র, মানি রসিদ, প্রবেশপত্র ও মার্কশিটের জন্য প্রিন্ট লেআউট প্রস্তুত রয়েছে:
- `@media print` এর মাধ্যমে প্রিন্টের সময় সাইডবার, ন্যাভবার ও একশন বাটনগুলো স্বয়ংক্রিয়ভাবে লুকিয়ে ফেলা হয় (`no-print` ক্লাসের মাধ্যমে)।
- ব্যাকগ্রাউন্ড কালার যাতে প্রিন্টে নিখুঁত আসে, তার জন্য `-webkit-print-color-adjust: exact !important` সেট করা আছে।
- থার্মাল পিওএস রসিদের জন্য ৮০ মিমি ফিক্সড উইডথ লেআউট রয়েছে।
